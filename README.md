## 演示操作

- 顶部固定导航仅保留01、02、03三个章节，点击可跳转；分项导航与进度随翻页更新。
- 左右方向键、Page Up / Page Down翻页，Home / End跳至首尾。封面可用Home返回。
- 点击“全屏”或按F全屏演示；“讲述提示”查看本页主讲与备讲说明。
- 计时可开始、暂停，双击归零；详情按Esc关闭。
- 第10页TACS任意点折返视频进入页面后自动静音循环播放，一轮约1分29秒；可展开详情，详情也自动循环。切页暂停离开页的视频，关闭详情后恢复当前页播放。
- 小铁宝挥手动图位于第10页业务场景入口及运行案例详情，动图自动循环；系统偏好减少动态效果时使用静态图。

主标题与内容小标题按字号、字重和间距分层。经验总结六项分别补充原文摘句，完整原文可展开查看。6号线专项数据按运行、车站、运维、绿色低碳分组；产业页展示产业单位、中标规模、创新矩阵及推广情况；工作建议页明确展示拟联合的中车、浪潮、中兴等单位。

- 资产总额采用用户最新确认的“超3700亿元”；职工1.5万人、委外及参建工人2.6万人分别列示。

- 人工智能覆盖目标按用户最新提供的文字稿截图，采用“力争‘十五五’期间，实现轨道人工智能100%场景全覆盖”。这是规划目标；“核心业务智能问答覆盖率超90%”为另一项业务指标。
- 6号线综合增效降本超30%、年节约成本约1亿元采用最新文字稿；专项指标由参考PDF和智慧车站素材补充，保持原统计范围。全线网506公里未来推广测算置于详情，绿色技术效益不全部归因为AI。
- 产业页总中标规模超9000万元，其中垂域大模型赋能产品超5000万元；两者为包含关系，不相加。专项实验室标明拟成立，申报建议保留拟联合状态。
- 已有成效、在研状态、规划目标及未来测算保留原文限定。数据核验说明与主讲分开，不同范围的数量不加总。

为保持主屏简洁，各页左下角引用说明、底栏引用版本及“讨论稿”字样已移除；来源记录和差异核验保留在维护材料中。线网图保留原图完整画面，含图例及明细表；小铁宝仅作为吉祥物视觉点缀，不对应技术指标。TACS画面保留“水灾为模拟场景”的说明。

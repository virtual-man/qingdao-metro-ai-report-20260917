## 演示操作

- 点击顶部固定章节导航直接跳转；同章内的页面进度随翻页更新。
- 使用左右方向键、Page Up / Page Down 翻页，Home / End 跳至首尾。
- 点击“全屏”或按 F 全屏演示。
- 点击“讲述提示”查看当前页主讲、可选补充与建议节奏。
- 点击“计时”开始或暂停，双击归零。
- 详情可按 Esc 关闭，展开期间仍可点击顶部章节导航。
